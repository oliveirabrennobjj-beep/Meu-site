# Ideia: dashboard do Brenno (fazer quando tiver computador)

Referência: `referencia-code-xr.jpg` (reel do @code.xr, "Dashboard V22").
Visual: fundo verde-escuro com brilho radial, cartões de vidro (glassmorphism),
cartões de números que sobem um pouco no hover.

Pilha vista no print: React, `framer-motion` (animações), `lucide-react` (ícones),
Tailwind (classes como `glass-card p-6 rounded-2xl`).

Quando for fazer, carregar: `brainstorming`, `frontend-design`, `impeccable`,
`ui-ux-pro-max`, `web-design-guidelines`, `ui-styling`, `design-system`, `dataviz`.
Instalar antes: `npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices -a claude-code --copy -y`.
