# Burgeria (modelo de hamburgueria)

Site de exemplo para hamburgueria artesanal. Pasta: `hamburgueria-modelo/`.

## Como ver
- Abra `index.html` no navegador (funciona dando dois cliques).

## Onde mudar
Tudo que é do cliente fica em `assets/js/config.js`:
- `nome`, `cidade`, `frase`, `lead`
- `whatsapp` (DDI + DDD + número, só dígitos)
- `endereco`, `horarios`, `mapa`
- `cardapio` (nome, descrição, preço, destaque)

Campo vazio = a parte some ou vira "Consulte pelo WhatsApp".
