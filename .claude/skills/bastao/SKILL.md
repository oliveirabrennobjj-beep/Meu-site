# Passagem de bastão

Atualize `memoria/passagem-de-bastao.md` para a próxima conversa começar de onde esta parou.

1. Reescreva a seção "Última atualização" com a data de hoje e três listas curtas:
   - **Pronto:** o que foi feito e funciona (com o caminho dos arquivos).
   - **Quebrado ou pendente:** o que falhou, o que falta e o que depende do Brenno.
   - **Próximo passo:** a primeira coisa que a conversa nova deve fazer.
2. Guarde só o que ainda importa. Tire da lista o que já foi resolvido.
3. Se apareceu informação fixa de algum assunto (preço, cliente, preferência), salve também no arquivo do assunto em `memoria/`.
4. Faça commit e push dos arquivos de `memoria/` no branch atual.
5. Responda ao Brenno em 3 a 5 linhas: o resumo e "pode abrir uma conversa nova".
